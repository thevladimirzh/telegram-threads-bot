1. The chart expects an existing Secret "{{ .Values.existingSecret }}" with keys:
   - BOT_TOKEN       — Telegram bot token
   - DATABASE_URL    — postgresql:// connection string
   {{- if eq .Values.mode "webhook" }}
   - {{ .Values.webhook.secretKey }} — X-Telegram-Bot-Api-Secret-Token value (D86)

     --from-literal=BOT_TOKEN=... --from-literal=DATABASE_URL=...

   {{- if .Values.webhook.ingress.enabled }}

   {{- end }}

   (ordered update handling — see values.yaml).
